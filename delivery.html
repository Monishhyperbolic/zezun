Courier API options

Providers to evaluate for a real integration.

“Free API” needs a distinction: documentation and test tools may be free to access, but a live courier account, API eligibility, shipping labels, freight, COD and other services can still be chargeable. None of the providers below should be assumed to offer unlimited free live shipping.

Shiprocket

Public API documentation

Order creation, courier/serviceability selection, labels, shipment status and tracking APIs.

Access: Create a Shiprocket account and API user in account settings. Confirm which subscription tier enables production API use before choosing it. Its Lite plan is advertised as free for up to 5 monthly shipments, with an average shipment cost shown as ₹45. The public pricing page does not specify whether Lite includes production API access, so confirm this before implementation.

API documentation · Current plans

Delhivery

Staging / test portal

PIN serviceability, rate calculation, shipment creation, tracking, labels, pickup requests and webhooks.

Access: Delhivery One client account and API token are required. The client developer portal supports testing; production shipment charges are separate.

B2C API docs · Test portal guide

Shipyaari

Public API docs + staging host

Serviceability and rate checks, placing shipments, labels, manifests and tracking.

Access: Seller account credentials generate a bearer token. Public docs list both staging and production API base URLs. Public documentation does not establish free unlimited production usage.

API documentation

Implementation note: keep API tokens on a server/backend, never in public HTML or browser JavaScript. First test PIN serviceability and rate estimates; only create a shipment after an order is confirmed and packed.

Recommended delivery logic

  1. Customer enters delivery PIN code.
  2. Backend checks courier serviceability and retrieves shipping options / rates.
  3. System adds product preparation and personalisation time.
  4. Checkout displays a delivery window with a clear estimate, not a guarantee.
  5. After dispatch, tracking updates come from courier API/webhooks.
